# 作业票管理系统 - React 版本

## 项目说明

这是一个使用 React 重构的作业票管理系统。原系统使用纯 HTML/JS 实现，存在一些维护问题：

### 已解决的问题

1. ✅ **list.html 无法回到首页** - 现在所有页面都有统一的侧边栏导航，可以轻松在页面间切换
2. ✅ **用户信息显示不统一** - 现在所有页面的侧边栏都显示当前用户名称和"退出"按钮

### 技术栈

- **前端**: React 18 + React Router v6 + Tailwind CSS + Vite
- **后端**: Express.js + SQLite3
- **图标**: Font Awesome 6

## 快速开始

### 1. 安装依赖

```bash
# 安装前端依赖
cd client
npm install
```

### 2. 启动应用

#### 启动后端服务器

在项目根目录运行：

```bash
node server.js
```

后端服务器将在 http://localhost:3000 运行

#### 启动前端开发服务器

```bash
cd client
npm run dev
```

前端开发服务器将在 http://localhost:5173 运行（如果端口被占用，会自动切换到其他端口）

### 3. 访问应用

打开浏览器访问前端地址（通常是 http://localhost:5173 或 http://localhost:5174）

## 主要功能

1. **用户认证** - 登录/登出功能
2. **工作台** - 数据统计和快速操作
3. **作业票列表** - 查看所有作业票，支持搜索
4. **新建作业票** - 创建各类特殊作业票
   - 动火作业
   - 受限空间作业
   - 高处作业
   - 吊装作业
   - 临时用电作业
   - 盲板抽堵作业
   - 动土作业
   - 断路作业
5. **作业票详情** - 查看作业票完整信息
6. **手写签名** - 支持手写签名功能
7. **驾驶舱模拟联动** - react-globe.gl 卫星地球与三级地名图层：中国层显示省级名称，四川层悬浮市州名称时按需显示对应行政区轮廓（无填充），泸州层显示红色定位
8. **应急处置大屏** - 应急流程、视频/智能交互预留区及五项实时刷新的模拟检测仪表
9. **受限空间作业增强** - JSA 附件、进出记录、气体检测表与五步流程引导

> 当前驾驶舱、应急仪表、视频/智能交互预留区和附件上传均为前端演示能力，刷新页面后模拟附件会重置；暂未接入客户真实设备、视频流、天气服务或文件存储。

## 开发说明

### API 代理

前端开发服务器配置了 API 代理，所有 `/api` 请求会自动转发到后端服务器（http://localhost:3000）。

配置文件：`client/vite.config.js`

### 构建生产版本

```bash
cd client
npm run build
```

构建后的静态文件将在 `client/dist/` 目录中。
